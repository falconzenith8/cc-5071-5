# 姿态交接演练视窗 · Pose Handoff Lab

游戏角色在**指定事件发生时**从动画控制交给受力姿态（ragdoll）：交接直接用当前骨骼的世界姿态与可估计速度初始化刚体链，不瞬移回默认站姿；交接后角色在场景接触中继续运动，可随时恢复动画。

## 启动界面

```bash
npm install
npm run dev          # 打开 http://localhost:5173
```

生产预览：

```bash
npm run build
npm run preview      # 打开 http://localhost:4173
```

界面是唯一入口，不是脚本演示。左半屏为角色与接触点，右侧面板为场景、受击范围、控制与结果区。

## 界面怎么用

1. 选场景：**行走中 / 转身中 / 斜面上**。三者共用同一套交接内核，区别只在动画剪辑与地面。
2. 选受力范围：**全身 17 根** 或 **上半身 9 根**。选上半身时，胸骨与脊柱之间的关节标为「边界」，下肢继续由动画驱动。
3. 点 **受击并接手** 触发交接。勾选「到点自动触发受击」则在该场景的剪辑时间点自动交接。
4. 结果区显示交接是否通过，并给出**逐骨骼**诊断表：归属、关节锚点误差、单步位移、去掉预期位移后的残差、动画速度 / 写入速度 / 物理速度、铰链角度、是否接地。
5. **恢复动画** 把控制权交回剪辑；**暂停** 冻结步进；**重置** 回到 t=0。
6. 可重放输入：**开始录制** → **受击并接手** → **导出回放** 得到 JSON；**载入** 后点 **回放**，从 t=0 用同一串输入重演。
7. 若交接未通过，画面顶部出现失败提示，**用同一录制输入重演** 会从 t=0 重放同一帧，用于定位失败骨骼。

## 接触感知恢复（图形入口）

右侧面板的 **接触感知恢复** 分组是恢复链路的唯一图形入口，所有判定都来自真实物理接触与场景射线，不存在“淡入站立模型”或关闭碰撞穿过障碍的路径。

1. **倒地方向**：仰卧 / 俯卧 / 侧躺，决定起身策略（仰卧滚起、俯卧撑起、侧躺翻身）。
2. **环境约束**：空旷 / 靠墙 / 低顶。墙与低顶会在角色实际倒地位置旁边生成，用来验证接触限制。
3. 点 **受控倒地**：角色通过真实碰撞管线被引导到倒地姿态并稳定，接触流形就绪。
4. 点 **接触感知起身**：先规划再执行。规划面板会显示恢复依据——朝向分类、采用策略、支撑法线与接触数、头顶 / 侧向 / 前后净空、逐阶段需要的净空，以及根目标（由当前身体位置就地推导，水平位移显示在依据里，而非传送到预设点）。
5. 起身通过真实骨骼层级的前向运动学逐阶段驱动，驱动 PD 力刻意弱于接触响应：碰到低顶或被墙压住时会先暂停，超过暂停窗口仍无法展开才判定不可恢复，碰撞始终开启。
6. 不可恢复时顶部出现 **恢复不可行** 提示并列出阻挡原因（低顶 / 墙体 / 超出行程等），角色保持受力姿态，不会穿过障碍；调整环境后点 **重新评估** 可再次分析。
7. 成功起身的最后一步把剪辑姿态按根位置增量重定基到实际恢复位置，再平滑交回动画控制，所有权审计保持通过。

### 恢复用例与核验要点

| 用例 | 操作 | 核验 |
| --- | --- | --- |
| 仰卧起身 | 仰卧 + 空旷 → 受控倒地 → 接触感知起身 | 骨盆抬升到站立高度、水平漂移受限、关节锚点不裂开、模式回到「动画控制」 |
| 俯卧起身 | 俯卧 + 空旷 | 撑起链路完成，铰链角不超出 `rig.ts` 限位 |
| 侧躺起身 | 侧躺 + 空旷 | 翻身再起身，根目标沿用倒地位置 |
| 低顶不可恢复 | 任意方向 + 低顶 | 规划判定不可行，提示「低顶」，角色停在受力姿态 |
| 靠墙阻挡 | 仰卧 + 靠墙 | 前后净空不足，提示墙体阻挡；切回空旷重新倒地后可正常起身 |
| 斜坡起身 | 场景选「斜面上」 | 以实测支撑法线对齐，脚与地面保持接触 |

命令行（`npm run verify` / `npm run e2e`）只用于辅助核验这些图形操作背后的内核行为；实际演练都在浏览器面板里完成。

## 交接判据（结果区与测试共用）

- 关节锚点误差 < 10 mm：刚体链没有在交接时裂开。
- 姿态残差 < 30 mm：单步位移减去「动画本应走出的一步」后的真实误差，用来排除正常的动画位移。
- 速度写入误差 < 1e-6 m/s：写进刚体的速度与动画估计速度一致，证明速度是继承来的而不是归零。
- 所有权审计：动画持有的骨骼必须是运动学刚体，受力骨骼必须是动力学刚体，同一关节不会被两套系统同时写。

受击冲量在**审计的那一步之后**才施加，因此它不会污染连续性与速度继承的测量。

## 测试

```bash
npm run verify       # 交接连续性、2s 稳定性与接触感知恢复单元测试
npm run e2e          # Playwright 端到端（需本机 Chromium 依赖）
```

单元测试覆盖三个场景的交接连续性、交接后 2 秒的有限性与关节拉伸上限、上半身受力的边界关节，以及接触感知恢复：朝向分类、根目标就地推导、真实支撑接触、低顶 / 挡墙不可恢复、三种倒地方向的完整起身链路、斜坡靠墙、恢复全程碰撞不关闭、以及在恢复根位置交回剪辑。端到端测试覆盖从界面触发、恢复、上半身边界标记、三个场景、回放导出/导入，以及通过图形面板完成的受控倒地 → 接触感知起身 → 控制交接与不可恢复提示。

## 结构

- `src/core/rig.ts`：骨骼定义唯一来源（坐标、碰撞形状、关节锚点、限位）。
- `src/core/animator.ts`：确定性程序化动画，逐骨骼中心差分速度，脚部支撑保持接地。
- `src/core/physics.ts`：交接内核（刚体链构建、速度继承、审计、稳姿辅助、障碍几何、接触与射线查询）。
- `src/core/recoveryPoses.ts`：倒地姿态、朝向分类、分阶段起身关键帧与关节限位钳制。
- `src/core/recovery.ts`：恢复规划器（接触 / 净空 / 阻挡判定）与起身状态机。
- `src/core/simulator.ts`：模式机、输入日志、录制与重演、受控倒地与恢复编排。
- `src/view/`：Three.js 渲染；`src/main.ts` 只做界面绑定。
